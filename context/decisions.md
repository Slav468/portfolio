# Context — Decisions (ADR)

## ADR-001: SCSS вместо Tailwind

- **Решение:** Использовать SCSS (Dart Sass) с CSS custom properties и BEM.
- **Почему:** Пользователь не хочет Tailwind. SCSS даёт вложенность, переменные, миксины и лёгкую замену токенов.
- **Когда:** Этап 1, 28.10.2026.

## ADR-002: Вариант дизайна 2 — Тёмный неон / Киберпортфолио

- **Решение:** Тёмная тема по умолчанию, неоновые акценты (циан, фиолетовый), стеклянные карточки, мягкие анимации.
- **Почedy:** Кибер-эстетика подходит для портфолио фронтенд-разработчика.
- **Когда:** Этап 1, 28.10.2026.

## ADR-003: Цветовая модель OKLCH

- **Решение:** Все цвета в OKLCH через CSS custom properties в `styles/_tokens.scss`.
- **Почему:** OKLCH даёт perceptually uniform цвета, легко заменяются в одном месте, поддерживают альфа-канал.
- **Когда:** Этап 2, 28.10.2026.

## ADR-004: Локальные шрифты

- **Решение:** Шрифты Geist Sans + JetBrains Mono в формате .woff2, хранятся в `public/fonts/`, подключаются через @font-face.
- **Почему:** Пользователь хочет локальные шрифты, легко заменяемые.
- **Когда:** Этап 2, 28.10.2026.

## ADR-005: Переключатель тем

- **Решение:** data-theme на <html>, сохранение в localStorage, учёт prefers-color-scheme.
- **Почему:** Пользователь запросил переключение светлая/тёмная тема.
- **Когда:** Этап 2, 28.10.2026.

## ADR-006: 10 stub-проектов

- **Решение:** 10 проектов-заглушек в `src/data/projects.ts`, заполнены агентом, подлежат замене на реальные из GitHub/локально пользователем.
- **Почedy:** Нужно чтобы было что показывать на этапе 4, пользователь предоставит свои проекты позже.
- **Когда:** Этап 4, 28.10.2026.

## ADR-007: Контактная форма → console.log + зелёное оповещение

- **Решение:** Server Action принимает форму, валидирует через Zod, выводит в console.log сервера, пользователю показывается зелёное оповещение об успехе.
- **Почedy:** Бэкенд под вопросом, позже прикрутят Telegram бота и email.
- **Когда:** Этап 6, 28.10.2026.

## ADR-008: Цвет успеха — зелёный

- **Решение:** `--color-accent-success: oklch(0.65 0.20 140)` используется для оповещения об успешной отправке формы.
- **Почedy:** Пользователь запросил зелёный для успеха.
- **Когда:** Этап 6, 28.10.2026.

## ADR-009: Алиасы импортов

- **Решение:** Настроены TypeScript path aliases (`@/*`, `@components/*`, `@features/*`, `@lib/*`, `@data/*`, `@styles/*`) в `tsconfig.json` с дублированием настроек в `next.config.ts` и `eslint.config.js`.
- **Почему:** Удобные короткие импорты вместо относительных путей (`../../../components/...`), единая точка правки при перемещении папок.
- **Когда:** Этап 1, 28.10.2026.
